## 用途

本目录仅保留 pi 与飞书、微信渠道参考，供开发时查阅。其它后端参考已随单 pi 收敛移除；历史背景见 [需求变更记录](../requirement-changes.md)，不作为当前集成指南

## 条目规范

- 一个引用对象一个文件，文件名用小写短横线（如 `pi-cli.txt`、`feishu-bot-api.md`）
- 信息来源可由用户直接补充，也可让 Agent 搜索获取后写入，写入时注明来源
- 内容过期时直接更新文件，不留历史版本
