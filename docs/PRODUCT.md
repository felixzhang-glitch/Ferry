# PRODUCT

## 产品定位

个人使用的消息 → 本机 pi 桥：通过飞书 / 微信 / PWA 与 pi 对话，agent 能力由 pi 原生承载，Ferry 只做消息编排、渠道适配与可见聊天界面

## 功能项清单

> 状态取值：规划中 / 开发中 / 已完成 / 已废弃。单 pi 收敛已完成自动化回归；“已完成”表示实现完成，不代表真实渠道上线验收

| 功能 | 状态 | 描述 |
|---|---|---|
| 飞书渠道 | 已完成 | WS 长连接 + webhook 入口，签名校验、解密、格式化回发、图片/文件处理 |
| 微信渠道 | 已完成 | iLink Bot sidecar，webhook token 校验，文本、入站图片（多模态喂 pi）/文件归档及出站文件 |
| PWA 聊天渠道 | 已完成 | 图标头部、右滑打开左侧会话列表、自动标题/手动改名、可滚动斜杠菜单、移动防误缩放；文本/附件、流式与后台续跑/重连、最终正文定稿；Cookie + CSRF，不支持离线发送 |
| PWA 系统通知与外观 | 已完成 | Web Push 后台回复、提醒与每日任务通知；主动授权、撤销、测试，默认不在锁屏展示正文。名称/图标保存与本地照片转码；触感受平台限制，iOS 安装图标/名称可能需重新添加；生产配置和真机验收另行执行 |
| 多后端路由 | 已废弃 | 删除其它 CLI 实现与后端选择状态，旧切换命令仅提示已移除 |
| 唯一 pi 接入 | 已完成 | `app.main` 直接装配 `PiCliClient`；`/backend`、`/pi` 只读状态，不切换、不重置会话 |
| 模型注册与切换 | 已完成 | `conf/pi/models.json` 版本化，启动自动同步到 `~/.pi/agent/`；PWA/飞书/微信共享模型与思考强度，控制台选择后下一轮生效；`PI_MODEL` 为启动默认值，未注册启动告警 |
| 会话与附件 | 已完成 | pi 管历史与压缩，客户端管 session 映射；`SessionManager` 仅管 key 与 pending_files，两渠道每轮只传 user |
| 会话命令 | 已完成 | `/new`、`/reset` 清附件与 pi 映射；`/compact`、`/compress` 只提示 pi 原生管理；保留 `/stop`、去重与 FIFO 排队 |
| 定时提醒 | 已完成 | 飞书/PWA `/remind 10m 喝水`，时间解析、持久化与恢复；PWA 结果保存在会话，授权后通知；保留微信现有限制 |
| 每日任务 | 已完成 | `/daily 08:00 简报`，创建 / list / cancel，持久化恢复，飞书/微信/邮件/PWA 投送；Web 失败投送复用已生成答案 |
| 时间感知 | 已完成 | 每轮由 `app.clock` 生成时间、时段与相对日期（昨天/明天/本周/下周），经 pi `--append-system-prompt` 注入；禁止心算与复读历史表述 |
| 规则与技能热加载 | 已完成 | 本地私有 `rules/system.md` / `rules/admin.md` 不入库、下一轮重读；`app.skills` 提供实时查询，技能摘要在新会话首轮注入 |
| 长期记忆 | 已完成 | `memory/` 明确要求时写入并回执，常驻注入，本地快照仓无 remote；文件为 NOTE-FORMAT（frontmatter + `[key] @date` observation + context 元数据），全部元数据投影到 `memory-index.json` |
| Dream 主动记忆 | 已完成 | 每日 `DREAM_TIME`（默认 02:00）离线读聊天增量，报告在 `DREAM_REPORT_TIME`（默认 08:00）推送，提炼长期事实、合并重复、归档过期；模型只提议 JSON ops，Python 校验（evidence 逐字比对用户原话、敏感信息过滤）后落盘并单独提交；摘要推送，`/memory` 状态、`/memory undo` 撤销、`/dream` 立即整理当前对话、`/dream all` 立即整理全部对话 |
| 文件与图片 | 已完成 | 入站图片经 pi `@file` 多模态输入、文件归档与附件通知、飞书图片回复、双渠道 `/push/file`；收敛不减少既有能力 |
| 图片多模态输入 | 已完成 | 两渠道入站图片经 pi 原生 `@file` 传给模型（飞书图文混排/微信图片）；大图 base64 回显由 32MB readline limit 承接；微信图片 AES 密钥支持纯 hex |
| 配置迁移兼容 | 已完成 | 后端参数统一 `PI_*`，旧共享键仅作回退；`GENERATED_IMAGES_DIR` 接替旧键；不自动迁移目录或删除数据 |
| 推送密钥扫描 | 已完成 | pre-push 扫描待推送新增行，fail-closed 阻断 |
| Ferry 控制台（原可观测看板） | 已完成 | 独立进程 `127.0.0.1:38080/observability/`，用户名 + 密码登录（默认 `admin`），会话 30 天持久化；监控（轮次、耗时、Token、工具与回发、`/metrics`）+ 控制（记忆整理、定时任务、系统设置）；只能在白名单选项中选择，不能自由写入；DeepSeek Harness 风格、跟随系统明暗；可添加到 iOS 桌面（PWA） |
| 邮件推送渠道 | 已完成 | 163 SMTP SSL，Dream 报告与每日任务都可推到 `MAIL_RECIPIENTS` 中的邮箱；授权码发送时才从文件读取 |
| pi 历史 Token 用量 | 已完成 | 只读扫描 pi 原生 JSONL 到独立不过期账本；7/14/30/90 天、自定义与全部历史、180/365 天热力图、模型堆叠趋势、缓存读取率与 Top5 |

## 非目标

- 不重复实现 pi 原生历史、上下文压缩和工具能力
- 不引入数据库 / Redis，不做多实例部署
- 不保留其它后端、切换路由或扩展框架
- 观测不做告警、费用估算与多用户权限；只统计启用后的运行事件，不回填聊天历史
- 上线与真实配置变更仅在用户明确授权后执行，不自动迁移或删除既有用户数据
