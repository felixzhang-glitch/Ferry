      • 总 Token = 输入 + 缓存读取 + 缓存写入 + 输出；推理 Token 已包含在输出中，不重复相加

      • compaction（压缩）和 branch_summary（分支摘要）用量计入总量；没有模型标记时显示「未标记/压缩」，不猜测所属模型
